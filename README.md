# Симуляция парковки

Практика №6 по дисциплине «Практика создания веб-приложений».

Условия:

- на старте 3 места, количество можно менять
- каждую секунду приезжает машина и стоит 5-10 секунд
- если мест нет, машина уезжает (отказ)
- доп. место стоит 100 руб., содержание места 20 руб. в секунду, доход с машины 300 руб.

Приложение показывает количество обслуженных машин, отказы, загруженность,
доход, затраты и прибыль, а также список мест со статусом.
Кнопка «Посчитать» прогоняет симуляцию для 1-15 мест и находит самое выгодное
количество. При этих условиях получается 8 мест.

Используются только useState, useEffect и setInterval.

## Запуск

```
npm install
npm run dev
```
